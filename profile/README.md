# Peira Labs

Tools for people who run their own servers. Honest scope, no telemetry, no
lock-in — built against a real home lab and released only when they're good
enough to hand to someone else.

Everything is at **[peira.dev](https://peira.dev)**.

## Projects

- **[peira](https://github.com/peiralabs/peira)** — a native desktop control
  panel that puts a whole homelab on one screen: Proxmox management, Prometheus
  metrics, media-stack status, an AI chat for any OpenAI-compatible endpoint,
  and an embedded terminal. Flutter/Linux, eight themes, signed releases.
- **[field-tools](https://github.com/peiralabs/field-tools)** — eleven
  single-file browser tools for self-hosters. No signup, no tracking, no build
  step; save one to a USB stick and it still works.
- **[deadair](https://github.com/peiralabs/deadair)** — checks whether a
  gluetun + qBittorrent stack is actually moving traffic, not just configured.
  A synced port is not the same as bytes arriving.
- **[youth-almanac](https://github.com/peiralabs/youth-almanac)** — free clubs,
  classes and events for ages 6–18, collected from public library and museum
  calendars.
- **[revision-agreement](https://github.com/peiralabs/revision-agreement)** — a
  conformance spec for derived-consumer currency: every read reports the
  revision it was served from, and disagreement fails closed.

## Principles

- **No telemetry.** Nothing phones home.
- **Verifiable releases.** Checksums, signatures, and build provenance where
  binaries ship.
- **Honest boundaries.** Each project states what it does *not* do and what it
  assumes about your setup.
